# PRODIGY_WD_03
Tic-Tac-Toe Web Application
Task-03 | ProDigy Infotech Internship

Project Description
This project is a browser-based Tic-Tac-Toe Web Application developed using HTML, CSS, and JavaScript. It allows two players to play against each other on a 3x3 grid. The application handles user interactions, checks for win or draw conditions, and provides a reset option to start a new game. The user interface includes gradient styling and clear layout for a smooth and engaging experience.

Technologies Used
HTML5 for structuring the game board

CSS3 for styling and layout

JavaScript for implementing game logic and interactivity

Features
Two-player game mode

Real-time click handling and turn switching

Game status updates: Win, Draw, or Ongoing

Reset button to restart the game

Responsive design for mobile and desktop

Visual effects using gradient styles

Folder Structure
TicTacToe-WebApp
├── index.html
├── style.css
├── script.js
└── README.md

How to Use
Download or clone the project folder

Open the file named index.html in a web browser

Click any cell to start playing

Alternate turns between Player X and Player O

The application will automatically check for a winner or a draw

Use the Reset button to play again
